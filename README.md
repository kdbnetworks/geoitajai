# GeoItajaí – Fork Experimental

Este repositório é um fork experimental do projeto original GeoItajaí.

O objetivo desta derivação é explorar melhorias incrementais relacionadas a:

- Experiência do usuário (UX)
- Interação geoespacial
- Organização e clareza estrutural do código
- Simplificação de fluxos operacionais

Esta versão não constitui implementação oficial e não representa qualquer órgão público ou instituição.

## Objetivos

- Reduzir fricções na navegação e nos fluxos de uso
- Aprimorar a manipulação de coordenadas e interação com mapas
- Refatorar trechos específicos visando maior legibilidade e modularidade
- Documentar decisões arquiteturais para futura evolução

## Escopo

O fork preserva a lógica estrutural do projeto original, propondo ajustes pontuais e controlados para fins de estudo, experimentação e melhoria técnica.

## Aviso

Trata-se de trabalho derivado independente, desenvolvido com finalidade experimental e de aprimoramento técnico.
Todos os créditos relativos ao conceito e à implementação original pertencem ao(s) autor(es) do repositório de origem.
